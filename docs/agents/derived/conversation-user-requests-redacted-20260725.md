雅思口语评分标准：考官是怎么打分的
你的雅思口语分数是四项独立评分的平均值。理解考官在每个维度、每个分数段具体看什么——这是提分最快的方式。很多考生盲目练习，不知道自己到底差在哪里。弄清评分标准，你才能有针对性地提高。
四大评分维度
每个维度从0到9分打分。最终的口语分数 = 四项平均分，四舍五入到最近的0.5分。
Fluency and Coherence（流利度与连贯性）
这个维度评估的是你说话有多流畅、思路有多清晰。它不是评估你说话有多快——而是你能否持续输出、逻辑连贯、不频繁停顿。
